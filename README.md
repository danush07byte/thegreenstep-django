Project Description

The Green Step is a web-based climate awareness platform developed to support Sustainable Development Goal 13 (Climate Action). The website educates users about climate change, promotes sustainable practices, and allows volunteers to register for environmental campaigns and activities.

Technologies Used

* Python
* Django
* HTML5
* CSS3
* SQLite
* Render (Deployment)
* GitHub (Version Control)

Features

* Home Page with SDG 13 information
* About Page with climate action details
* Volunteer Registration Form
* Admin Panel for managing volunteer registrations
* Responsive and user-friendly interface
* Live deployment using Render
